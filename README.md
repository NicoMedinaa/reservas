# reservas
This web API was designed for managing a quincho in a residential building. An administrator accesses it via "website.com/admin" to configure reservations and register tenants' DNI (national ID). On the /login page, a user is only approved if their DNI is registered. After logging in, the user must verify their email. Each user can only have one active reservation at a time (a requirement from the client). When a tenant moves out, the admin can deletes their data entirely.

In the latest version, a new feature was added that allows the admin to manage various categories related to the building's shared expenses.
